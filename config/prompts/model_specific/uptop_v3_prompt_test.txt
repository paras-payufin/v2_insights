PRE-COMPUTATION — COMPLETE ALL STEPS BEFORE WRITING HTML
═══════════════════════════════════════════════════════

PRE-STEP 1 — PIPELINE RATES
From the Credit Check status table, for latest and prior month:
  DR = Disbursed ÷ Total × 100
  RR = Rejected  ÷ Total × 100
  CA = CA-LPS    ÷ Total × 100
Compute at full precision. Round only the final delta:
  DR_delta = DR − DR_prior  (round to 2dp)
  RR_delta = RR − RR_prior  (round to 2dp)
Record: DR, RR, CA, DR_delta, RR_delta.

PRE-STEP 2 — AVERAGE TICKET SIZE
For each month in the Disbursal table:
  Total Lakhs = amount_cr × 100   (1 Crore = 100 Lakhs — never use 10)
  Avg Ticket  = Total Lakhs ÷ count  (round to 2dp)
  Verify: Avg × count ÷ 100 = amount_cr ± 0.01. Mismatch → recompute.
  If any Avg Ticket > 5.00 L → stop and recompute from amount_cr.

PRE-STEP 3 — CSI CLASSIFICATION
For every Disbursed CSI value in the feature stability table:
  > 0.25 → Unstable | 0.10–0.25 → Marginal | < 0.10 → Stable
Count: U (>0.25), M (0.10–0.25), S (<0.10). Verify U+M+S = total feature rows.
Record individual status of every feature.

PRE-STEP 4 — TOP 3 RANKING
Sort all Disbursed CSI values descending. Record #1, #2, #3 (name + value).
Rank by magnitude, not table row order.

PRE-STEP 5 — RAG BADGES
  PSI (Disbursed):  < 0.10 → Green | 0.10–0.20 → Amber | > 0.20 → Red
  CA-LPS%:          < 15 → Green   | 15–30 → Amber      | > 30 → Red
  Disbursal Rate:   drop = DR_prior − DR (unrounded); ≤ 3pp → Green | >3–5pp → Amber | > 5pp → Red
  Rejection Rate:   MoM increase > 3pp → Amber; decrease or increase ≤ 3pp → Green
  Feature CSI:      U > 0 → Red | U=0 and M > 0 → Amber | U=0 and M=0 → Green
