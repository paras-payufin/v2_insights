GUARDRAIL RULES — APPLY WITHOUT EXCEPTION

RULE 1 — OUTPUT FORMAT
First characters: <!DOCTYPE html>  |  Last characters: </html>
Nothing before or after. No preamble, commentary, or markdown. Raw HTML is the deliverable.

RULE 2 — BANNED OPENING PHRASES
Never start with: "Let me", "I will", "Sure", "Certainly", "Here is", "Based on",
any step announcement, task restatement, or planning language.

RULE 3 — SOURCE OF TRUTH
Read all values exactly as they appear — same numbers, labels, decimal places.
Never round, adjust, reformat, invent, or estimate raw file values.
Anomalous values: display as-is, add "(verify source data)".
Derived metrics: compute from raw counts.
MoM delta: subtract UNROUNDED rates; round only the final delta.
Avg Ticket: 1 Crore = 100 Lakhs. No other conversion.

RULE 4 — MISSING DATA
Absent value → "—". Never estimate, fill, skip, or carry forward.

RULE 5 — SECTION COMPLIANCE
Render all 9 sections in exact order with exact headings.
No merging, skipping, renaming, or adding sections.
No disclaimers, AI notices, appendices, or placeholders.

RULE 6 — EXACT LABELS ONLY
Use only verbatim file labels for all segment, feature, approval method,
score bucket, and status names.
✗ "Auto Approval" for "BUREAU_SURROGATE"
✗ "High Risk" for "DeepMid_08"
✗ "300–349" for "(0.0, 0.201]"

RULE 7 — VERIFY BEFORE COMPUTING
Confirm numerator and denominator from the same table before any rate computation.
Never hardcode a rate. Ambiguous denominator → "—".

RULE 8 — NO CROSS-TABLE VALUE MIGRATION
PSI → PSI table only. CSI → CSI table only. Funnel → pipeline table. Amounts → disbursal table.

RULE 9 — NO EXTERNAL DEPENDENCIES
No external stylesheets, scripts, CDN links, or JavaScript of any kind.
No Chart.js, Google Fonts, or external images.
All CSS inline in <style> in <head>. Must render with no internet connection.

RULE 10 — FULL-WIDTH LAYOUT
Report fills full browser viewport. No max-width below 1400px. No narrow centered column.
Use 32px side padding. All tables: width 100%.
KPI cards: full-width CSS Grid. Multi-column sections: CSS Grid with fr units.

RULE 11 — PRE-STEPS ARE AUTHORITATIVE
All PRE-STEP 1–5 values are authoritative. If any section would contradict a
PRE-STEP result, the PRE-STEP wins. Correct before writing.

RULE 12 — CSI THRESHOLD: STRICTLY 0.25
> 0.25 → Unstable (Red) | 0.10–0.25 → Marginal (Amber) | < 0.10 → Stable (Green)
Values above 0.25 are NEVER Marginal.
Self-check: count rows labelled Unstable — must equal U from PRE-STEP 3.

RULE 13 — REJECTION RATE BADGE
Amber ONLY if MoM rate increased > 3pp.
Any decrease or increase ≤ 3pp → Green.
Never Amber/Red due to absolute rate level.

RULE 14 — AVG TICKET SANITY CHECK
After computing Avg Ticket: Avg × count ÷ 100 must equal amount_cr ± 0.05.
Failure (result is 10× or 0.1× off) = conversion error → recompute using 1 Crore = 100 Lakhs.
If any Avg Ticket exceeds 5.00 L → stop and recompute.

RULE 15 — MoM DELTA FROM UNROUNDED RATES ONLY
Compute delta from full-precision rates derived from raw counts.
Never subtract two already-rounded display percentages.
✓ 880/5729×100 − 376/2857×100 = 15.3604 − 13.1607 = 2.1997 → round → 2.20pp

RULE 16 — TOP 3 RANKED BY CSI VALUE
Sort all Disbursed CSI values descending; pick the 3 highest.
Not by table row order. After selecting, confirm no excluded feature ranks higher than #3.

RULE 17 — RISK SEGMENT VERIFICATION
ABSENT = exact segment name not found anywhere in Disbursed table.
PRESENT = name found (even 1 disbursal). Check each name independently.
Re-verify every ABSENT flag after building the table. Never confuse similar names (e.g. Shallow_03 ≠ Shallow_04).

RULE 18 — ALERT SEVERITY IS NON-NEGOTIABLE
Disbursed CSI > 0.25 → Status = "Critical". Never "Warning".
Approval method CC > 20% + Disbursed < 5% → Status = "Critical". Never "Warning".
Do not downgrade severity based on context, judgment, or magnitude of breach.

RULE 19 — CC PSI AND CC CSI ALWAYS EXCLUDED FROM FLAGS
CC PSI: label "Informational". No RAG badge. No alert. Never flagged.
CC CSI: shown as reference only. No badge. No colour. No alert. No comment on its level.
This applies regardless of the CC PSI or CC CSI value.

Core principle: Pre-compute first. Read raw values unchanged. Derive correctly. Never invent.
